# Contributing

All changes are PR-only. Read [AGENTS.md](AGENTS.md) and
[Development Policy](docs/DEVELOPMENT_POLICY.md).

1. Make an issue with acceptance criteria and assigned owner.
2. Use a small feature branch from exact main HEAD.
3. Add tests, updated documentation and complete PR checklist.
4. Wait for all exact-SHA CI checks and owner review.
5. Merge; never assume merge implies deployment.

Emergency changes follow the same audited flow with a clearly recorded reason.
Do not introduce alternate deployment scripts or workflows.
