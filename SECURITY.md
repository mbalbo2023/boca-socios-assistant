# Security Policy

Do not disclose credentials, tokens, cookies or personal data through GitHub
issues or pull requests. Report suspected security issues directly to the
repository owner through a private channel.

Supported security posture: **foundation/simulation only**. Live traffic,
payment automation and credential onboarding are not enabled in this release.

See [docs/SECURITY.md](docs/SECURITY.md) for encryption, key custody, backups,
data deletion and incident handling requirements.
